# Probability for ML

Work through these assignment notebooks in order. Each has starter cells, expected outputs, acceptance criteria, automated checks, and written interpretation prompts. They are assignments, not completed solutions.

1. [`01_events_conditional_bayes_independence.ipynb`](01_events_conditional_bayes_independence.ipynb): event counts, conditional probability, Bayes' rule, independence, and rare-event alert precision.
2. [`02_random_variables_expectation_variance.ipynb`](02_random_variables_expectation_variance.ipynb): PMFs, expectation, variance, Bernoulli/binomial simulations, and expected decision cost.
3. [`03_covariance_correlation_distributions.ipynb`](03_covariance_correlation_distributions.ipynb): covariance, Pearson correlation, basic distributions, outlier sensitivity, and leakage-aware feature exploration.

After these notebooks and the applied-statistics topics, complete the independent [fraud alert capstone](../03_applied_statistics/03_capstone_fraud_alert_evaluation.ipynb).

For each lesson, finish the code and explanation, retain the provided assertions, then restart the kernel and run all cells in order. Expected failures must be caught in test cells.
