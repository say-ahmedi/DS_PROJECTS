# Computer Vision to Junior ML Engineer: November 4, 2026–March 11, 2027

## Operating rules

Target **30 hours over six study days**: 18 hours CV project/engineering, 4 math, 2 SQL, 2 technical English, 3 eligible-job search/interviews, 1 weekly review. University work and wellbeing remain in the personal schedule. When time falls below 25 hours, protect the detector, evaluation, and applications; shorten the NLP extension first.

The inspected RTX 3050 Laptop GPU has **4 GB VRAM** and the installed PyTorch is CPU-only. Before training, install a compatible CUDA build in a project environment and verify `torch.cuda.is_available()`. Use small pretrained models, short controlled runs and batch 1–2. A free cloud GPU is a fallback.

## Portfolio evidence

1. [PPE detector](projects/01_ppe_detection/README.md): reproducible train/development/final-test split, baseline and one controlled comparison, per-class AP and missing-PPE recall, 30 inspected failures, latency, API and Docker demo. **In progress.**
2. Form OCR and field extraction on [FUNSD](https://github.com/crcresearch/FUNSD): preprocessing comparison, character error rate, field F1, 20 inspected failures and a runnable demonstration. **Scheduled for Weeks 9–13.**
3. Banking intent classification on [BANKING77](https://huggingface.co/datasets/PolyAI/banking77): TF-IDF/logistic-regression baseline versus small transformer, macro-F1, per-class results and latency. **Scheduled for Weeks 14–15.**

Do not mark a project complete until a clean environment can reproduce its reported evaluation and sample inference.

## Mathematics sequence

| Weeks | Topics | Checkpoint |
|---|---|---|
| 1–2 | Tensor shapes, matrix multiplication, broadcasting, normalization | Explain `[batch, channels, height, width]`; finish existing linear-algebra notebooks. |
| 2–4 | Derivatives, chain rule, gradients, gradient descent | Hand-calculate one update and compare with autograd. |
| 2–6 | Pixel and normalized box coordinates, resize/flip, IoU, precision/recall, AP | Run the [IoU exercise](projects/01_ppe_detection/math/01_boxes_iou.md) and box-coordinate tests. |
| 4–7 | Convolution, stride/padding, pooling, softmax, cross-entropy, overfitting | Implement a tiny convolution and explain learning curves. |
| 5–12 | Probability, variation, class imbalance and uncertainty | Explain per-class detector results and missing-PPE recall. |

Use [PyTorch basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html), [Stanford CS231n](https://cs231n.stanford.edu/), [OpenCV transformations](https://docs.opencv.org/5.0/main_modules/imgproc_transform.html), and the relevant parts of [DeepLearning.AI mathematics](https://www.deeplearning.ai/specializations/mathematics-for-machine-learning-and-data-science). Pause proof-heavy topics that do not unblock the current project.
